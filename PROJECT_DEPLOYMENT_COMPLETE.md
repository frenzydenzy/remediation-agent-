## Key Content

### Architecture Overview
```
Developer Code
    ↓
Process 1: Context Acquisition
  • Manual context discovery
  • Java import auto-parsing
  • Related file discovery
    ↓
Process 2: Validation & Analysis
  • AI-powered security review
  • Vulnerability identification
  • Findings report generation
    ↓
Process 3: Automated Fixation
  • Isolated remediation branch
  • Per-fix testing
  • Automatic rollback on failure
    ↓
Developer Reviews & Merges
  • Manual push
  • PR creation
  • Final approval
```
